UNDERWORLD EMPIRE — GODOT STARTER PROJECT
==========================================

This is a playable single-player prototype for Godot 4.3 or later.
It is an original, text-and-interface-based crime empire management game,
not a copy of another game's artwork, characters, or branding.

FEATURES
- Portrait/mobile-friendly layout
- Cash, respect, HQ level, crew size, and heat stats
- HQ upgrades
- Crew recruitment
- Operations with success/failure odds, rewards, and risk
- Passive income collection
- Local save file on the device

OPEN ON ANDROID
1. Extract this ZIP into a folder on your phone.
2. Open Godot Android Editor.
3. Import/open the project by selecting the folder containing project.godot.
4. Open Main.tscn if it does not open automatically.
5. Press Run (play triangle).

If the editor's import picker cannot browse ZIP contents, use your phone's Files app to extract
the ZIP first, then import the extracted folder.

IMPORTANT
This is a playable prototype, not a finished commercial release. It has no online multiplayer,
store purchases, original illustrated map/artwork, sound, account system, analytics, or signed
Google Play App Bundle yet. A Google Play release requires testing, a signed AAB, store listing,
privacy/data declarations, and compliance with current Play policies.
